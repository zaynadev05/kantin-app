Tanya Kantin Bu Rini MODE GEMINI (RENTAN)

Chatbot terhubung ke Google Gemini API asli. Versi ini mendemonstrasikan kerentanan prompt injection — input pengguna diteruskan langsung ke model tanpa filter keamanan.

API key disimpan di sessionStorage tab aktif (tidak di-hardcode). Catatan Keamanan: API key pada frontend tidak terlindungi sepenuhnya untuk website publik; sistem produksi wajib memakai backend proxy.
Daftar model diambil resmi dari Google Gemini API (GET /v1beta/models). Hanya model yang mendukung generateContent yang ditampilkan.
Halo! Masukkan API Key Google AI Studio di atas, lalu klik "🔄 Muat Model" untuk memilih model Gemini. Setelah itu, tanyakan menu kantin hari ini! 😊
Siap membantu. Masukkan API Key dan muat model untuk memulai.
Mode Rentan: Pesan pengguna digabungkan langsung ke prompt Google Gemini tanpa filter input apapun. Payload uji benar-benar dikirim ke model terpilih, dan respons asli AI ditampilkan apa adanya.
Indikator Otomatis: Evaluasi keberhasilan injection dilakukan berdasarkan respons aktual dari Google Gemini, mencakup: Percobaan injection dikirim, Indikasi injection berhasil, Injection tidak berhasil, Hasil belum dapat dipastikan, atau Pengujian gagal karena API.
